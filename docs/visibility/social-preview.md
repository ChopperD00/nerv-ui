# Social preview asset

`assets/nerv-ui-social-preview.png` is an original abstract command-center visual created for this project. It contains no third-party logo, character, screenshot, or text.

The same image is served at `public/social-preview.png` and referenced by the site’s Open Graph and Twitter metadata. To set GitHub’s repository-level social preview manually, open **Repository settings → General → Social preview**, upload this file, and save. GitHub’s REST API does not provide a repository social-preview upload endpoint, so this action was not automated.

The README’s existing `docs/references/readme-surveillance-preview.gif` remains its product-motion asset with the static `banner.png` above it as a fallback. Its historical generator relies on missing local capture frames; regenerate it only after adding a reproducible browser-capture workflow.
