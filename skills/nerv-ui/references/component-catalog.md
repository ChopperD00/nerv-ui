# Component catalogue

Import all components from `@mdrbx/nerv-ui` and styles from `@mdrbx/nerv-ui/styles.css`.

| Goal | Components |
| --- | --- |
| Structure and navigation | `Card`, `TargetingContainer`, `MonitorOverlay`, `NavigationTabs`, `Breadcrumb`, `Stepper`, `Divider`, `Drawer` |
| Forms and choices | `Button`, `InputField`, `SelectMenu`, `Textarea`, `Checkbox`, `Toggle`, `RadioGroup`, `FileUpload` |
| Data and feedback | `DataGrid`, `TerminalDisplay`, `Badge`, `Skeleton`, `Pagination`, `StatusStamp`, `SegmentDisplay`, `SyncProgressBar` |
| Visual status | `Gauge`, `BarChart`, `PieChart`, `SyncRatioChart`, `GradientStatusBar`, `PhaseStatusStack`, `PatternAlert` |
| Overlays and actions | `SystemDialog`, `DropdownMenu`, `Tooltip`, `NervToastProvider`, `useToast`, `ClassifiedOverlay` |
| Command-center detail | `MagiSystemPanel`, `SurveillanceGrid`, `TargetingReticle`, `CountdownTimer`, `WireframeLoader`, `EmergencyBanner` |

For full prop details and live examples, visit https://mdrbx.github.io/nerv-ui/docs/ and https://mdrbx.github.io/nerv-ui/examples/.
